# Jago Dither 1.6.0

Turn artwork into printed textures, limited-colour images and animated dithering. Free, local and editable.

This repository contains the application source, examples, licence notices and illustrated guide. See **DEVELOPING.md** to build it. Ready-to-use Windows downloads belong under GitHub Releases.

## Get started

Read **Documentation/Jago-Dither-Guide.pdf** for an illustrated introduction. The app’s **?** menu provides help and shortcuts. Start with a blank project or explore the editable examples. Save your editable project as well as any finished exports. Each studio works independently; Workscape is optional.
