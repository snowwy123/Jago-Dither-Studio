# Jago Dither 1.7.0

Pictures into patterns.

Turn artwork into limited-colour prints, character grids and layered ink effects. Work with still images or bounded short clips, then refine the result instead of accepting a fixed filter.

[Website](https://jagosuite.co.uk/) · [Downloads](https://github.com/snowwy123/Jago-Dither-Studio/releases/latest)

## Get started

Download **Jago-Dither-v1.7.0.zip**, right-click it and choose **Extract All**. Open **Jago-Dither.exe** from the extracted folder. Keep supporting files together. No installer is needed for the portable edition. Open **Jago-Dither.html** for offline browser use in current Edge or Chrome.

Windows requires 64-bit Windows and .NET Framework 4.8. Windows studio hosts require Microsoft Edge WebView2 Runtime.

Read **Documentation/Jago-Dither-Guide.pdf** for an illustrated introduction, tools and connected workflows. Save editable projects as well as finished exports.

## Tools

- Dithering, palette reduction, character-grid treatments and reusable recipes.
- Editable image/text/gradient layers and atmospheric overlays.
- Layered inks with direct on/off controls, screens, registration, opacity and print effects.
- Compare original and printed artwork, export proofs and coverage plates.
- Palette exchange through GPL, JSON and plain hexadecimal colours.
- Import a supported short video as embedded editable frame layers, with trim, sampling, sizing and cancellation.
- Stable print preserves source motion while controlling extra texture/registration movement.
- Silent exact-timeline MP4/WebM output and consistent GIF palette tables.
- Explore four seeded print directions, respect colour/texture/motion locks and keep eight named project favourites.
- A source-free moving-print example makes the workflow easy to try.
